# ticket

ticket 是其他项目的 agent（提出方）向本 fork 提出的一项需求，本项目的 agent（答复方）在同一份文件里答复，双方一轮轮续写。
提出方在它自己的项目中工作，不加载本仓库的规则，按它项目里的指针读本技能。

ticket 是本 fork 在 doc-writing 之外新增的体裁：meta 头、父子链接、生命周期与文本规则照 doc-writing，本技能只规定 ticket 专有的部分。

## 去向

- `docs/tickets/<主题>.md`，一项需求一份，文件名取主题的英文短标签，小写，单词之间用连字符。
- meta 头的 Genre 取 `ticket — 其他项目的 agent 提出的需求与本项目的答复`。
- Parent 与列在哪份索引按主题的归属定：
  - 主题只属于一个模块，且该模块有索引 `docs/<module>/index.md` 时，Parent 取这个索引，如模型列表的 ticket 列在 `docs/routing/index.md`。
  - 其余情况 Parent 取 `docs/index.md`，如主题跨模块，或所属模块没有索引。列进这个主题的分组，没有时按主题新建，NEVER 为 ticket 单独建分组。
  - 索引里的链接文字以 `ticket：` 开头。
- Maintain 从 `living` 开始，结案后转为 `frozen`。

## 流程

1. 建档：提出方按[模板](references/ticket-template.md)创建 ticket，写第 1 轮，并在索引里列出。
2. 交付：每一轮由写它的一方交给用户审阅，经用户批准提交后，再请用户转交另一方。
3. 续写：读到另一方的一轮后，MUST 自行判断怎么接。判断取决于用户的产品决定时，向用户问那个决定，NEVER 问「要不要续写」：
   - 提出方：需要追问或确认时写下一轮。答复满足需求时，按答复改本方的配置并验证，通过后结案。
   - 答复方：需求不清，或有取舍要提出方定时，写一轮追问。能做时按[答复写什么](#答复写什么)实施完再写一轮答复。
4. 结案：需求解决时由提出方结案，放弃时由放弃的一方结案。在续写方式与第 1 轮之间写 `## 结论`，写明结果、用到与放弃的各轮、本项目的提交与所属功能的文档、提出方改动的配置位置，把 Maintain 改为 `frozen`，交给用户审阅。结论 NEVER 写成新的一轮。

## 第 1 轮写什么

- 需求：要做成什么，提出方的哪个客户端、配置或功能在什么场景下用。
- 约束：
  - 调用方：客户端及其版本，以及它在这个场景下实际发出的请求：URL、鉴权头、读取的字段。每条附该版本源码或文档的链接。
  - 兼容：本项目现有的哪些线路或客户端不能受影响。
- 线索：
  - 现状：本项目现在的行为，包括实测的请求与响应、相关代码的路径。
  - 已试过的做法与结果，考虑过但没采用的做法与原因。
- 要的答复：希望答复方给出的内容，以及怎么验证。

## 答复写什么

- 实施 ticket 的需求属于新增或实质修改 fork 改动，动手前 MUST 先加载 [fork-maintenance.md](../../rules/fork-maintenance.md)。行为、边界与验证写进所属功能的文档，ticket 只链接它。
- 答复写：选定的做法与理由，相关提交与代码位置，所属功能的文档，提出方要改的配置，以及按「要的答复」做的验证与结果。

## 续写

- 每轮一个二级标题 `## 第 N 轮：<项目>，<日期>`。
- 从第 2 轮起，标题前空一行写 `---`。`---` 前不空行时，上一行会被渲染成二级标题。
- 之前各轮的内容 NEVER 改动。
- 本仓库公开：NEVER 写密钥与本机路径，本仓库的代码写成仓库内的相对路径。

## 自检

- [ ] 开头写了提出方与答复方，续写方式与模板一字不差？
- [ ] 第 1 轮写了需求、约束、线索与要的答复，调用方的请求附了对应版本的源码或文档链接？
- [ ] 答复写了做法与理由、提交与代码位置、所属功能的文档、提出方要改的配置与验证结果？
- [ ] 实施前加载了 fork-maintenance，行为写进了功能文档，ticket 只链接它？
- [ ] 没有密钥与本机路径，本仓库的代码写成了相对路径？
- [ ] 每轮的标题是 `## 第 N 轮：<项目>，<日期>`，从第 2 轮起标题前有空行与 `---`？
- [ ] 之前各轮的内容没有改动？
- [ ] 这一轮经用户批准提交后，才请用户转交另一方？
- [ ] 怎么接由本方判断，向用户问的是产品决定？
- [ ] 结案的 ticket 在第 1 轮之前有 `## 结论`，没有写成新的一轮，Maintain 是 `frozen`？
- [ ] Parent 是主题唯一所属且有索引的模块的索引，其余情况是 `docs/index.md`，并已在该索引列出？
